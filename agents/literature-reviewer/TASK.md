# Literature review task template

For `{H_ID}`:
1. Normalize terminology independently of project-specific names.
2. Build a query matrix: exact structure, synonyms, stronger/weaker forms, special cases, transformed coordinates, and unusual proof fingerprints.
3. Search multiple scholarly indexes/sources and record exact query + date.
4. Perform backward and forward citation chasing for close candidates when available.
5. Compare every close result by domain, assumptions, quantifiers, conclusion, strength, and proof idea.
6. Produce only one assessment: `UNRESOLVED`, `LIKELY_KNOWN`, or `NO_EQUIVALENT_FOUND`.
