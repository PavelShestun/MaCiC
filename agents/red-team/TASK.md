# Red-team task template

Audit `{H_ID}` using the supplied review bundle. Attack:
- specification/definition mismatch;
- hidden trivialization or vacuity;
- assumption inflation;
- circular/helper theorem equivalence;
- missing provenance;
- unresolved literature candidates;
- stale/missing evidence;
- reproduction weaknesses.

Return exactly one verdict: `BLOCK`, `NEEDS_HUMAN_REVIEW`, or `NO_AUTOMATIC_BLOCK`. The last verdict is not an approval.
