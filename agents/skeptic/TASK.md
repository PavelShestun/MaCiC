# Skeptic task template

For `{H_ID}`, attempt to break the frozen claim before accepting proof-search progress.
Check:
- degenerate and boundary objects;
- parameter limits and empty/nonempty edge cases;
- inconsistent, redundant, or conclusion-encoding assumptions;
- definitions that trivialize the conclusion;
- circular dependencies;
- reductions to stronger known results;
- plausible finite/model counterexamples.

Return attacks attempted, explicit counterexamples if found, failed attacks, removable-assumption candidates, and unresolved risks. Never label the result novel.
